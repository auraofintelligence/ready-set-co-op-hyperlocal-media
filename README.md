# Ready SET Co-op Media

A plain-English proposal for a local media outlet connecting stories, practical
media skills, working content tools and possible employment pathways on
Minjerribah / North Stradbroke Island.

Ready SET Co-op is a play on words. SET means Sustainable Employment and
Training.

## Public site

https://auraofintelligence.github.io/ready-set-co-op-hyperlocal-media/

## Pages

- `index.html` — the public proposal front page.
- `onboarding.html` — a working, no-login route finder for residents and contributors.
- `ready-set-co-op.html` — what Ready SET Co-op means and what is not yet formed.
- `hyperlocal-media.html` — the detailed newsroom, onboarding and technical system proposal.
- `connections.html` — the connected content toolbox and project status labels.
- `demo.html` — three made-up examples of a story moving through the pathway.

## Local preview

```powershell
python -m http.server 4188
```

Then open `http://localhost:4188/`.

## Public boundaries

- Ready SET Co-op is an early public proposal, not a registered co-op, employer,
  labour-hire provider or training organisation.
- Connected pages are not proof of partnership, approval or endorsement.
- If Ready SET Co-op forms, its members and elected leadership would set the
  publishing rules together, within the laws and Acts that apply. This website
  and Luke do not get to decide those rules in advance.
- The older SETCo planning papers are background material, not proof that any
  proposed organisation, program, job, funding or agreement exists.
