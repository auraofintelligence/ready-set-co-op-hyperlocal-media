# Ready SET Media

A plain-English public guide connecting local stories, practical media skills,
working content tools and possible employment pathways on Minjerribah / North
Stradbroke Island.

## Public site

https://auraofintelligence.github.io/ready-set-co-op-hyperlocal-media/

## Pages

- `index.html` — the community front door.
- `ready-set-co-op.html` — what Ready SET means and what is not yet formed.
- `hyperlocal-media.html` — the careful local-story pathway.
- `connections.html` — the connected content toolbox and project status labels.
- `demo.html` — three made-up examples of a story moving through the pathway.

## Local preview

```powershell
python -m http.server 4188
```

Then open `http://localhost:4188/`.

## Public boundaries

- Ready SET is an early public proposal, not a registered co-op, employer,
  labour-hire provider or training organisation.
- Connected pages are not proof of partnership, approval or endorsement.
- Cultural authority, privacy, safety and legal responsibility remain with the
  right people; an AI or media tool cannot decide those matters.
- The older SETCo planning papers are background material, not proof that any
  proposed organisation, program, job, funding or agreement exists.
