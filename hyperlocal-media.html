The production flow

Six stages, with a human decision before release.

Contributors would use a short, plain form instead of a complicated publishing dashboard. The production team would receive the details in a review queue.

01

Intake

Receive a tip, event, voice note, photo, interview idea, correction or official-source link.

Capture:title · exact date · source · location level · public contact · files · what remains unknown
02

Verify

Check the source, names, dates, links, status and what has actually been approved for public use.

Result:verified · needs follow-up · hold · do not publish
03

Edit

Prepare plain copy, captions, transcript, sound, images, cuts and accessible versions.

Keep attached:source trail · status label · edit notes · correction contact
04

Approve

A responsible person makes the final publishing decision. Automation does not cross this gate.

Decision:release · revise · schedule · return · reject
05

Publish

Prepare only the versions needed for the website, social feed, newsletter, audio or screens.

Each output shows:source · time checked · status · link to more detail
06

Archive

Keep the approved master, sources, permission boundary, version history and correction path.

Purpose:accountability · reuse · training · grant evidence · local memory

Community onboarding architecture

One link, then a route that fits the person.

A QR code or public link could open a simple welcome page, help each person choose what they need and offer optional follow-up updates.

NeedChoose the immediate job

Distribution architecture

One approved source, several deliberate outputs.

Publishing everywhere is not the goal. The system prepares only the format needed by each audience and keeps the source status visible.

Website

Full context

Article, links, transcript, sources, update time and correction path.

Newsletter

Useful summary

A short digest that sends readers back to the full source page.

Social

Clear entry point

Caption, short clip or tile that does not pretend to hold the whole story.

Audio

Listen anywhere

Interview, bulletin or podcast segment with a companion source page.

Community screen

Glanceable notice

Large type, essential facts, checked time and a way to find more.

Archive

Local record

Approved master, versions, sources and correction history.

Sustainable Employment & Training

Break mixed-media production into learnable roles.

These are possible media roles, not advertised jobs. Start with supervised production work, then build the employment structure properly if the Co-op goes ahead.

Entry taskSource checker

Confirm a link, date, spelling or public status.

Entry taskCaption assistant

Prepare captions, alt text and a clean transcript draft.

ProductionPhone reporter

Record a stable shot, clean sound and a short approved interview.

ProductionEditor

Shape words, sound and vision while keeping the source trail attached.

OperationsCommunity coordinator

Route contributions, answer questions and keep the queue moving.

OperationsProducer / station lead

Hold the editorial calendar, final workflow, funding and public reporting.

A buildable launch sequence

Test the work before buying the full stack.

Phase 01

Listen + specify

Test the onboarding routes, story fields, status labels and approval gate with willing people.

Phase 02

Run one desk

Publish one small recurring format using manual review and the existing public tools.

Phase 03

Choose and build the system

Set up publishing, contributions, media storage and community updates using what the production team has learned.

Phase 04

Train + report

Define supervised roles, show what was produced, what it cost and what should happen next.

Publishing authority

The proposal cannot appoint itself.

If Ready SET Co-op forms, its members and elected leadership would set the publishing rules together, within the laws and Acts that apply.

This website and Luke do not get to decide those rules in advance.
